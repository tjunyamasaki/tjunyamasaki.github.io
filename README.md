# Lobby

Play at **https://tjunyamasaki.github.io**

Everyone needs internet (to load the page). For a table, join the **same Wi-Fi or Player 1’s hotspot**.

1. Open the link. Enter a nickname.
2. **Host:** tap **Host lobby**. Share the room code. Keep this tab open.
3. **Others:** enter that code and tap **Join**.
4. Use **Toggle ready** and **Bump counter** to check everyone is in sync.

If the host closes the tab, reopen **the same browser** and tap **Resume room**. Guests wait or tap **Join** again with the same code. **Leave** ends the table for good.

Up to 15 people.
