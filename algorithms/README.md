# Kinetic — Algorithm Theater

Logic, in motion. Sixteen algorithms unfold across four living scenes.

Open **[Algorithm Theater](https://tjunyamasaki.github.io/algorithms/)** and watch.
Tap the algorithm's name to choose a different way of thinking.

- **Sorting:** Quick, merge, heap, bubble, insertion, and selection sort. Tap the bars to reshuffle.
- **Graphs:** Breadth-first search, depth-first search, Prim's algorithm, and Kruskal's algorithm. Tap a node to move the starting point; Kruskal uses the whole network, so tapping remixes it instead.
- **Mazes:** Recursive backtracker, randomized Prim, and randomized Kruskal. Every maze carves itself, then reveals its solution. Tap to grow another.
- **Routes:** A*, Dijkstra, and greedy best-first search on a terrain map. Tap land to move the destination. Sand costs 1, forest 3, high ground 6; water cannot be crossed. A* and Dijkstra find a least-cost route. Greedy search may take a more expensive path.

Pause, remix, or change the pace with the three controls below the scene. Sound is optional and starts muted. The corner expansion button opens an immersive view; swipe horizontally to change scenes.

With the canvas focused, **Space** pauses or plays, **Enter** or **R** remixes, and the **left/right arrows** change scenes. **Escape** closes immersive view. Selecting another algorithm keeps the same data, so you can watch a different approach to the same problem.

Reduced-motion preferences start the theater paused and remove decorative motion. Background tabs pause automatically. Completed animations begin again with fresh data; with reduced motion enabled, each run stops on completion.
