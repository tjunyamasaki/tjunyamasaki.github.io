# Legacy art

The first Hollowstead artwork, kept for reference only. Nothing in the game loads
these files.

- `themes/harvest/sprites/` — the original SVG theme sprites (128 x 192 cells).
- `assets/magic/` — the original Gravecraft PNGs, the per-pack strips and the
  generation prompts.

The current art is generated by `tools/art/build.py` in the Hollow Harvest ink
style. See `themes/FORMAT.md` for the sheet layouts.
