Pixel editor

Load a reference, align a grid over it, paint pixels, export PNG or a project file. Nothing leaves this tab.

References

    Drop or paste images. Click a name to use it as the background. The pixel layer stays put when you switch. Drop a .pixel.json project to restore drawing, grid, and references.

    Add a reference image, then align the grid over it.

    Grid

    Drag the grid or use Move grid (Alt-drag also works). Drag the corner handle to change cell size. Arrows nudge; [ ] change cell size. Trace paints a cell with the average background color under it. Trace area: drag a rectangle, then each cell in it is traced. Trace all does the whole grid. Magenta chroma is skipped.

    Colors

    Used in this drawing. Eyedrop or click a swatch.

    Export

    Project JSON reloads this drawing, grid size and offset, colors, and reference images. PNG is the pixel layer only.
