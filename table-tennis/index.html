Table tennis

Host a group. Everyone plays everyone. Guests join the room to watch the grid, ranking, and remaining matches. Only the host can edit.

How it works
  • Host keeps this tab open and shares the room code.
  • Add players, or just record a result — new names are created.
  • Each pair plays once. The grid cell is sets won against that player.
  • Ranking: match wins, then set difference, then sets won, then head-to-head.
  • Tap a name to see who they beat and who they still need to play.
  • Host can add groups, edit any match, or remove a player.
  • Export CSV downloads every recorded match as name,sets,name,sets.
